# Task: palindrome

Write a JavaScript module `solution.js` in this directory that exports a function `isPalindrome(s)`.

Rules:
- `isPalindrome(s)` returns `true` if `s` reads the same forwards and backwards.
- Comparison is case-insensitive and ignores all non-alphanumeric characters.
- Empty string (or a string with no alphanumeric characters) is a palindrome.

Use CommonJS (`module.exports`). Do not modify `test.js`.
