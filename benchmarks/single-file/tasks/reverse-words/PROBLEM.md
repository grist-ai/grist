# Task: reverse-words

Write a JavaScript module `solution.js` in this directory that exports a function `reverseWords(s)`.

Rules:
- `reverseWords(s)` reverses the characters of each word, keeping word order and spacing exactly as-is.
- Words are maximal runs of non-space characters; spaces (including multiples) are preserved verbatim.

Use CommonJS (`module.exports`). Do not modify `test.js`.
