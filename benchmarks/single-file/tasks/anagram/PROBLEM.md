# Task: anagram

Write a JavaScript module `solution.js` in this directory that exports a function `areAnagrams(a, b)`.

Rules:
- `areAnagrams(a, b)` returns `true` if `a` and `b` contain exactly the same characters with the same multiplicities.
- Comparison is case-insensitive and ignores spaces.
- All other characters (punctuation, digits) are significant.

Use CommonJS (`module.exports`). Do not modify `test.js`.
