# Task: capitalize

Write a JavaScript module `solution.js` in this directory that exports a function `capitalizeWords(s)`.

Rules:
- `capitalizeWords(s)` uppercases the first character of each word and leaves all other characters unchanged.
- Words are separated by single spaces in the test inputs; preserve every character (including spacing) except the case change.
- Empty string returns empty string.

Use CommonJS (`module.exports`). Do not modify `test.js`.
