# Task: intersection

Write a JavaScript module `solution.js` in this directory that exports a function `intersection(a, b)`.

Rules:
- `intersection(a, b)` returns the values present in both `a` and `b`.
- Result follows the order of first appearance in `a`, with duplicates removed.
- Equality is `SameValueZero` (like `Array.prototype.includes`).

Use CommonJS (`module.exports`). Do not modify `test.js`.
