# Task: chunk

Write a JavaScript module `solution.js` in this directory that exports a function `chunk(arr, size)`.

Rules:
- `chunk(arr, size)` splits `arr` into sub-arrays of length `size`. The last chunk may be shorter.
- If `size <= 0` (or not a positive integer), return `[]`.
- The input array is not modified.

Use CommonJS (`module.exports`). Do not modify `test.js`.
