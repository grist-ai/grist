# Task: bst

Write a JavaScript module `solution.js` in this directory that exports a class `BST` (binary search tree of numbers).

Rules:
- `insert(v)` — inserts number `v`. Duplicate values are ignored. Returns `this`.
- `has(v)` — returns `true` if `v` is in the tree.
- `inorder()` — returns the values in ascending sorted order.
- `size()` — returns the number of values in the tree.

Use CommonJS (`module.exports`). Do not modify `test.js`.
