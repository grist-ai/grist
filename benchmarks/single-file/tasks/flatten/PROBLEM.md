# Task: flatten

Write a JavaScript module `solution.js` in this directory that exports a function `flatten(arr)`.

Rules:
- `flatten(arr)` returns a new array with all nested arrays recursively flattened.
- Non-array values are kept as-is, in order.
- Empty arrays contribute nothing. The input array is not modified.

Use CommonJS (`module.exports`). Do not modify `test.js`.
