# Task: fizzbuzz

Write a JavaScript module `solution.js` in this directory that exports a function `fizzbuzz(n)`.

Rules:
- `fizzbuzz(n)` returns an array of strings for numbers 1..n inclusive.
- For multiples of 3, use "Fizz" instead of the number.
- For multiples of 5, use "Buzz" instead of the number.
- For multiples of both 3 and 5, use "FizzBuzz".
- All other entries are the decimal string of the number.
- `n` is a positive integer. For `n <= 0`, return an empty array.

Use CommonJS (`module.exports`). Do not modify `test.js`.
