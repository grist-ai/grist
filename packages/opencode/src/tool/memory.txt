Recall or record verified project memory (pre-POC §6 — verified outcomes only).

Use `action=recall` to search ownership/convention memories for this project.
Use `action=remember` only for verified outcomes:
- tests_passed — a check you ran just passed and the fact is durable
- user_approved — the user explicitly confirmed the fact
- user_corrected — the user corrected a wrong assumption

Never remember speculative or unverified generations.
Disable with GRIST_MEMORY=off. Prefer Supermemory when SUPERMEMORY_API_KEY is set;
otherwise stores locally in .grist/memory.json.
