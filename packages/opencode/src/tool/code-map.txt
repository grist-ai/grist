Query the project code map for a compact subgraph (SoL-Pi / pre-POC context minimization).

Use when you need blast-radius or related symbols instead of grepping the whole repo.
Prefer this before reading many files on exploration or escalation.

Arguments:
- seed: file path, symbol name, or node id (e.g. "login", "src/auth.ts")
- hops: graph walk depth (default 2)
- maxNodes: soft cap on nodes (default 40)

Returns a token-cheap node/edge listing. Full graph lives on disk (Graphify `graph.json` or CRG).
Disable with GRIST_CODE_MAP=off. Point Graphify at GRIST_GRAPHIFY_PATH or graphify-out/graph.json.
