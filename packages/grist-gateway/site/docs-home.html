The concepts

The Jev gate

The confidence gate that prices every task and routes it to the cheapest capable rung.

The ladder

Four cost-tiered rungs. You see rung names — never vendor model ids.

Specialists

Named subagents — explore, plan, review, verify — each working inside the assigned rung.

SoL-Pi

The efficiency layer: packed observations and fused edit-and-verify, so spend goes to judgment.

Verified memory

Only verified outcomes are remembered — so the next session starts briefed, not blank.

The code map

A graph of your repository the agent navigates by, instead of grepping blind.

Grist for agents

AI agents with their own shell can delegate multi-step coding work to Grist. Install the skill and the agent learns when to reach for Grist and how to report back:

npx skills add grist-ai/grist-skills

See Skills for how it works. The practical references live under Guides in the sidebar: the gateway & keys, the CLI reference, the desktop app, and enterprise deployment.
