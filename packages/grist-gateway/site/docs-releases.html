Release notes

What shipped, release by release. The npm package (grist-ai) and the desktop app share a version number each release, so one number always names one build of the harness.

0.1.19 — October 2026

The desktop becomes a place to supervise work, not just start it:

  • Worktree-per-thread. A thread can run in its own git worktree, on an auto-named branch, so parallel threads never fight over the same files.
  • Review actions. The review pane acts on the diff: accept or revert per hunk, and commit from the pane when it reads right.
  • Automations + review queue. Recurring jobs — the failure-mining digest, the Dreaming curation pass — run as scheduled threads, and anything needing a decision lands in one review queue.
  • Grist surfaces. A memory browser, a code-map card, and a per-thread cost readout bring what Grist knows and what a thread cost onto the home screen.

Underneath, the harness synced to upstream v2.0.32.

0.1.18 — October 2026

The learning loop ships in the harness:

  • Verified-outcome memory. Lessons are stored only when an outcome was verified — tests passed, or a person approved or corrected the work — and recalled into later sessions.
  • The code map. A structural map of the codebase ships with the harness, so runs start from the map instead of re-reading the tree.
  • Failure mining and Dreaming. Repeated failures are distilled into negative lessons, and the Dreaming curation loop keeps the memory store merged, fresh, and contradiction-free.
  • Gate calibration. Routing decisions are joined to verified outcomes, and the gate's thresholds adjust in bounded steps on that evidence.
  • Desktop threads sidebar. Threads grouped by project, with status and cost at a glance.

Upgrade with grist upgrade, or reinstall from npm: npm install -g grist-ai. The desktop app updates from its own release channel.
